# “节后综合征”，你的颈腰椎还好吗？

> 更新时间：2026-09-16 (UTC+8)

欢乐忙碌的春节假期刚刚结束，陆军军医大学西南医院康复科就收治了不少出现腰酸背痛、头晕头痛、脖子酸沉、下肢麻痛、活动受限等症状的患者，评估检查后发现，他们都得了颈腰椎病！

什么是颈腰椎病？有什么症状？我们应怎么预防颈腰椎病？如果出现了颈腰椎病，康复治疗有哪些？陆军军医大学西南医院康复科治疗师为您解答！

**问**

什么是颈腰椎病？

**答**

颈腰椎病指以颈椎和腰椎退行性病理改变为基础一类脊柱疾病，主要与年龄、运动损伤、慢性劳损、遗传因素等有关。在诸多因素共同作用下，颈腰椎生理结构发生改变，如骨质疏松、椎间盘突出、韧带增厚等压迫脊髓或神经根，出现头颈部不适、手指麻木、腰腿疼等一系列功能障碍，医学上将这一类病症统称“颈腰椎病”。

**问**

颈腰椎病有哪些主要症状？

**答**

主要表现为头痛头晕、颈肩部疼痛、上肢疼痛酸沉、腰背酸痛僵硬、下肢放射痛、出现麻木、活动受限等症状，更有甚者出现头晕呕吐、视力模糊、走路跛行、大小便障碍、无法下床活动等严重症状。

**问**

为什么假期是颈腰椎病的高发期？

**答**

1.“交通病”：有人千里迢迢赶车回家，有人选择自家出游，一坐就是十几个小时，甚至几十个小时，长期保持一个姿势，让本就告急的颈腰椎苦不堪言。

2.“娱乐病”：春节期间，难得相聚，把酒言欢，搓麻打牌，看电视，打游戏等活动出现低头一族，长期久坐，昼夜颠倒，最后颈腰椎加重甚至复发。

3.“疲劳病”：春节期间忙打扫卫生、置办年货、准备丰盛的年夜饭、走亲访友……这些都避免不了长时间站立、弯腰、下蹲、起立等动作，使腰肌不堪“重负”，出现颈腰椎疼痛加剧。

**问**

日常如何预防颈腰椎病？

**答**

1. 保持正确姿势：避免长时间弯腰低头，不翘二郎腿腿、含胸驼背、葛优躺、低头族、注意正确坐姿睡姿。

2. 避免久坐，劳逸结合：每半个小时起来活动，做做颈腰椎锻炼操。

3. 注意保暖，合理用枕：尤其注重颈部腰部背部保暖，一旦感冒打喷嚏咳嗽会加大椎间盘压力，受凉则容易复发，枕头不宜过高，床垫不宜过软。

4. 保持良好的生活习惯：营养均衡，合理膳食可以提高抵御疾病的能力，建议多食新鲜蔬菜、豆类食品、高蛋白食品、水果牛奶。

5. 加强自我训练：颈部米字操、八段锦、太极拳、伸展运动、自我锻炼保健操。

**问**

康复治疗对颈椎病有哪些功效？

**答**

**针灸治疗**

通过刺激局部或者经络远端的腧穴疏通经络、活血化瘀，调理颈部气血，使气血经络得到顺畅，达到治疗效果。

**推拿疗法**

推拿具有舒经活络，滑利关节，缓解肌肉僵硬，有效解除小关节紊乱对颈腰椎神经及血管压迫，调整椎间关系，消肿止痛。

**物理因子治疗**

牵引治疗利用反作用力和作用力的原理使组织发生分离，进而周围软组织得到适当牵伸；干扰电缓解疼痛、加快损伤修复；激光消炎消肿，加快物质代谢作用；热敷缓解肌肉紧张，促进炎症吸收，改善微循环；超声波促进血液循环，加快组织修复，缓解挛缩等作用。

**运动疗法**

肌肉软组织牵伸和放松、关节松动术、麦肯基技术、运动训练等。
